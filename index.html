Como entrar

Dá para entrar pelo Minecraft Java ou pelo Bedrock (celular, Windows, Xbox, PlayStation, Switch). Quem joga Bedrock não precisa ter conta Java.

Java (PC)

Endereço impairment-joaquin.tun.ply.gg
  1. Abra o Minecraft Java na versão 26.3.
  2. Multijogador → Adicionar servidor.
  3. Cole o endereço acima (não precisa de porta) e entre.

Bedrock (celular, console, Win10/11)

Endereço impairment-radiated.tun.ply.gg
Porta 40852
  1. Atualize o Minecraft para a versão mais recente.
  2. Jogar → Servidores → role até o fim → Adicionar servidor.
  3. Cole o endereço e a porta acima em campos separados.

No jogo, nicks do Bedrock aparecem com um ponto na frente, por exemplo .Steve.

Não conseguiu entrar?

  • Java: confira se está na versão 26.3. Snapshots não entram.
  • Bedrock: a porta é 40852, não a padrão 19132.
  • Console: Xbox, PlayStation e Switch não deixam adicionar servidores direto; use um app como o BedrockTogether no celular na mesma rede.
  • Se o servidor não aparecer, ele pode estar desligado. Pergunte no grupo.

Como a live mexe no jogo

Cada streamer tem a live ligada ao próprio personagem. O que acontece depende do valor da doação.

Você doaManda um presente na live do TikTok ou um Pix pela LivePix do streamer.
O valor define a faixaPresentes contam em diamantes (custo × quantidade do combo); Pix conta em reais.
O mundo reageEm poucos segundos o evento acontece perto do streamer, com o seu nome na tela.
